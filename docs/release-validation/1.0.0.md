# PIX 1.0.0 検証記録

共通candidate準備、native受信、CARD status、USB、cleanupの手順と判定は [`../release-validation.md`](../release-validation.md) を正本とする。本書は初回matrix、現在のsource/Core checkpoint、候補の実証範囲と未実施項目を記録する。

## 1.0.0 初回matrix

この時間/targetは1.0.0だけに適用し、後続releaseへ自動継承しない。代表Linux x86_64を2時間、macOS arm64とWindows x86_64を各30分、その他全配布binaryを各10分試験する。7 binary全てをnative OS/architectureで短時間回帰し、全実地域地上波と全無料BS/CS targetを各10秒raw TS取得する。無料CSを省略しない。CS22複数ECMに関する既知Issueは1.0.0対象外として別記する。全channelの周波数・TSID・slotを現地計画と機種設定から固定する。各機種自体の一度以上2時間qualificationとmajor versionごとの全OS/architecture短TSは別に記録する。

## feature checks と結果

公開3コマンドは `pixd`、`pixctl`、`pix-ts`。PIXの内蔵カード状態は `pixctl card-status`、外部ATR/reset/APDUやPC/SC/WinSCardとは別機能である。1.0.0ではDT181/DT295のCARD status経路を製品固有手順に従って確認し、照会失敗時をunknownとして扱う。DT295の内部raw stateと物理カード在否の対応を未確認のまま補わない。stream中カード抜去/再挿入復帰は確認済み扱いにしない。

各実施行にはsource SHA、Core SHA、candidate run/artifact/archive SHA、native OS/architecture、機種、実command、物理操作、期待/実測、終了値とcleanupを記録する。final 1.0.0 candidateで未実施の行は理由とともに `未実施` / `未認定` とする。今回の文書変更ではsource・CI・実機検証を行っていない。
